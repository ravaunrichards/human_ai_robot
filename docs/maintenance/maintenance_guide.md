# Maintenance Guide (Preliminary)

**Status: PRELIMINARY.** Intervals are placeholders to be set from real duty
cycles and manufacturer guidance.

## Routine (proposed)
| Interval | Task |
|----------|------|
| Before each session | E-STOP test, visual cable/fastener check, fault log review |
| Weekly (in use) | Check joint play/backlash, thermal check under load |
| Monthly | Re-torque critical fasteners, inspect bearings, clean filters |
| As needed | Replace exterior panels / face shell (see below) |

## Exterior panel / face shell replacement
1. Power down and isolate; confirm de-energised.
2. Remove captive fasteners / release magnetic capture ring.
3. Inspect skin for tears/stains; clean with the material-approved agent only
   (to be confirmed for the selected silicone — do not guess solvents).
4. Replace shell; verify no mechanism fouling before re-energising.

## Service access
- Electronics, contactor and E-STOP must remain reachable behind labelled
  service-access covers without removing load-bearing structure.

## Spares
- Keep spare fuses, connectors, a face shell and high-wear bearings on hand once
  parts are finalised.
