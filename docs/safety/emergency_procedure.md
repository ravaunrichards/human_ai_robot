# Emergency Procedure

## If the robot moves unexpectedly or a person is at risk
1. **HIT THE E-STOP.** It removes actuator-bus power immediately.
2. Step clear of the keep-out zone; do not reach into the machine.
3. If E-STOP fails, **open the main power isolation** / unplug the bench PSU.
4. Do not re-energise. Record what happened (time, command, state, logs).
5. Investigate before any further power-up; log in `hazard_log.md`.

## If there is smoke / burning smell / thermal event
1. E-STOP, then isolate main power.
2. For a battery event, follow the pack's emergency guidance; evacuate if needed
   and use appropriate extinguishing media. Keep a suitable extinguisher nearby
   during any battery work.
3. Do not touch hot actuators/drivers.

## If electrical shock risk / exposed conductor
1. Isolate power before touching anything.
2. Treat casualties per site first-aid procedures; call emergency services.

## After any incident
- Quarantine the machine (de-energised, tagged out).
- File an incident note; update risk assessment and hazard log.
- Require re-review and sign-off before resuming (`signoff_record.md`).

## Human safety / self-harm note
This is an engineering document. If a person is injured, prioritise calling
local emergency services immediately over any equipment concern.
