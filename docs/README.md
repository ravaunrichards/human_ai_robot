# Documentation index

- `system_architecture/` — overview, AI/speech/vision/motion architecture, comm protocol.
- `mechanical_design/` — mechanical design, DOF table, skin system (all preliminary).
- `electrical_design/` — power architecture + conceptual block diagram.
- `wiring/` — wiring + connector templates (pinouts are TBD, not invented).
- `parts_list/` — BOM in Markdown + CSV (provisional; no invented prices/links).
- `assembly/` — assembly sequence + inspection checklist.
- `calibration/` — calibration procedure (fixtures, verified limits).
- `safety/` — **mandatory**: overview, risk assessment, hazard log, emergency
  procedure, pre-test checklist, commissioning, sign-off, privacy.
- `maintenance/` — maintenance + panel/skin replacement.
- `test_records/` — categorised test report + auto-generated raw output.

Every document carries an explicit status label. Preliminary / conceptual /
unverified items are marked as such; nothing unverified is presented as safe or
validated.
